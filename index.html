01

Technical Writing: Definition and Purpose

Definition

Technical writing is a form of communication that explains specialized information in a clear, accurate, organized, and understandable way. It is commonly used in academic, scientific, business, and technical fields.

Purpose of Technical Writing

  • To inform: Provide facts, findings, or explanations.
  • To instruct: Explain how to perform a task.
  • To analyze: Present information and evaluate results.
  • To recommend: Suggest solutions based on evidence.
Example: A user manual explains how to install and operate a printer. Its purpose is to help the reader use the product correctly.
02

ABC's of Technical Writing

These principles help writers create useful, readable, accurate, and professional documents.

Accuracy — Record data correctly.
Brevity — Be direct and concise.
Confidence — Communicate decisively.
Dignity — Treat readers courteously.
Facility — Make the report easy to understand.
Emphasis — Highlight important information.
Honesty — Cite sources and report truthfully.
Illustration — Use charts, graphs, and diagrams.
Judgment — Evaluate gathered information.
Knowledge — Gather relevant facts and data.
Logic — Arrange ideas using sound reasoning.
Mechanical Neatness — Keep the report neat and readable.
Normal Procedure — Follow accepted standards.
Objectivity — Avoid personal bias.
Planning — Establish purpose and direction.
Qualification — Evaluate which ideas to include.
Revision — Check grammar, spelling, and punctuation.
Straight Sentence — Write directly and use transitions appropriately.
Thoroughness — Provide sufficient details.
Unity — Maintain coherence among ideas.
Viewpoint — Establish the perspective of the writing.
Word Choice — Use clear, understandable words.
Zest — Write with energy and interest.
03

Outlining the Subject

An outline is a plan that organizes the main topic, major ideas, and supporting details before writing a document.

Steps in Outlining

  1. Identify the subject and purpose.
  2. Determine the audience.
  3. List the major points.
  4. Add supporting details.
  5. Arrange points in a logical sequence.
TOPIC: How to Use a Computer
I. Introduction
Purpose and equipment
II. Procedure
Start, log in, and use
III. Conclusion
Save work and shut down

The Basic English Structure

A basic English sentence usually contains a subject and a verb.

PatternStructureExample
SVSubject + VerbThe machine operates.
SVCSubject + Verb + ComplementThe result is accurate.
SVOSubject + Verb + ObjectThe student writes a report.
SVOOSubject + Verb + Indirect Object + Direct ObjectThe teacher gave the class an assignment.
SVOCSubject + Verb + Object + ComplementThe team found the solution useful.
06

Parts of a Letter

  1. Heading / Return Address: Sender's address.
  2. Date: Date the letter was written.
  3. Inside Address: Recipient's name and address.
  4. Salutation: Formal greeting.
  5. Body: Main message.
  6. Complimentary Close: Polite closing.
  7. Signature and Typed Name: Sender's signature and name.

Heading / Return Address

Graphs and Charts

Graphs and charts present numerical information visually. They help readers compare values and identify trends.

Common Types

  • Bar graph: Compares quantities among categories.
  • Line graph: Shows changes over time.
  • Pie chart: Shows how a whole is divided into parts.
